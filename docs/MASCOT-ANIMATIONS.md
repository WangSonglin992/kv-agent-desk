# AI 娘状态动画

三个 Agent 的状态区域使用透明 Q 版角色动画，三个内置主题共用同一渲染路径。

| Agent | 角色 | 空闲 | 工作中 | 忙碌 |
| --- | --- | --- | --- | --- |
| Codex / ChatGPT | 白发、浅紫龙角、龙翼和尾巴 | 抱杯休息、眨眼 | 使用笔记本电脑 | 快速操作、紧张表情和小汗滴 |
| ZCode / GLM | 黑发、深色衣服、狐耳和书 | 抱书休息、眨眼 | 阅读和记笔记 | 快速翻书写字、纸页和汗滴 |
| Antigravity / Gemini | 蓝紫长发、猫耳、异色瞳和星饰 | 休息、眨眼、尾巴小动作 | 使用笔记本电脑 | 更快的动作、紧张表情和星形点缀 |

状态仍由原有适配器捕获：可靠任务数超过 3 才判为忙碌。等待输入保留准确文字提示；来源未知或未接入不会伪装成正在工作。过期数据继续沿用已有的最近可信状态与低调提示。

## 素材与动画

- 三张本地图集位于 `agent_dashboard/assets/mascot_{chatgpt,glm,gemini}.png`，均为 512 × 384 RGBA PNG。
- 每张图集固定为 4 列、3 行；依次为空闲、工作中、忙碌，每行 4 帧。空闲周期约 4 秒、工作中约 2 秒、忙碌约 0.65 秒。
- `agent_dashboard/mascots.py` 只读取三个预置文件名，缓存解码后的帧。素材损坏、缺失或来源不受支持时，保留原来的状态指示器。
- 动画时钟与数据采集分开，离线播放不增加模型或账户接口请求。窗口预览和 USB 屏幕使用同一帧渲染。
- 空闲的四帧按常规每秒刷新推进；工作和忙碌沿用原来的快速刷新节奏，不为眨眼增加整页的高频空闲刷新。
- 自定义布局继续使用原有状态元素 ID，保存的外观副本不需要重新导入。状态文字仍由代码控制，布局模板不能更改业务内容。

## 生成记录

使用内置 `image_gen` 工具生成，参考用户提供的 AI 角色插画，只取其中的 ChatGPT 与 Gemini 角色方向，并按用户描述补充黑发、深色服装、拿书的 GLM。没有采用豆包形象，也没有把原始参考图加入仓库或发布包。

共用提示词要点：透明背景；同一角色、同一服装与比例；4 列 × 3 行等宽等高图格；每格完整、保持同一基线；适合 64 像素状态区域的清晰 Q 版轮廓；不绘制文字、网格或界面。第一行休息和眨眼，第二行专注工作并交替手部动作，第三行快速工作、表情更紧张并有少量汗滴。

角色提示词分别锁定白发浅紫龙娘、黑发持书学者、蓝紫猫耳星饰少女。ChatGPT 与 Gemini 的工作行使用小型电脑，GLM 的工作行使用书和笔。图集生成后仅进行固定尺寸缩放与 PNG 打包，不重绘角色。

素材来源、署名及独立的 CC BY-NC-SA 4.0 插画许可见 [SOURCES.md](../agent_dashboard/assets/SOURCES.md)。应用源代码仍按 MIT 发布。

## 维护

新增或更换角色时需要同时更新 `mascots.py` 的固定映射、图集、PyInstaller 的显式资源列表、wheel 的 package-data 及公开文件白名单。不要通过 UI JSON 接受任意路径、URL 或可执行内容。回归检查应使用合成数据，覆盖三种状态、三套主题、旧布局偏移和素材缺失回退。
